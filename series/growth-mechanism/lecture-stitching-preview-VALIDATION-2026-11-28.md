## 3. 独立镜头资源核验

预览中的 21 个独立镜头路径均已在当前 `main` 分支目录树中找到，无缺失引用。

同步方式按各镜头实际接口分别处理：

| 镜头 | 同步方式 |
|---|---|
| 03–06 | 使用各自原生 `window.__cue03–06.sync(ms)`；以 `pause=1` 初始化为暂停状态 |
| 07–10 | 原始 V2 没有统一父页面同步 API；父页面在 iframe 加载后注入轻量桥接，按其实际全局变量和 `render()` 控制时间 |
| 11–14 | 使用各自已有的 `pause()` 与 `seek(seconds)` 接口 |
| 15–18 | 原始 V1 没有统一父页面同步 API；父页面在 iframe 加载后注入轻量桥接，不修改原始镜头文件 |
| 20–24 | 使用各自嵌入版已有的 `sync(ms)` 接口 |

Cue 20 的反馈修正镜头具有独立的时间缩放系数；其接口接收全片时间轴毫秒值，再映射到镜头内部时长。Cue 21–24 的接口按各自实际实现传入毫秒值。

## 5. 尚未完成的运行时验证

本次执行环境没有可控的本地项目浏览器，也无法取得 GitHub Pages 页面在真实 Chromium 中的执行上下文。因此，以下项目**没有被标记为通过**：

- GitHub Pages 页面实际加载与音频解码；
- 播放、暂停、重播、拖动进度的真实交互；
- 逐镜头切换时的黑屏、闪烁、跳时和动画重置；
- 画布裁切、遮挡、边缘越界和实际视觉尺寸；
- 不同设备视口下的实际显示。

因此，本记录是静态集成与接口核验，不是浏览器运行验收，更不是用户视觉验收。后续应在实际浏览器中完成全片播放与视觉审阅，再决定是否调整镜头或进入正式总片合并阶段。
