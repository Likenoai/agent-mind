# 反馈与修正｜独立镜头 V4

## 本次修正
移除原先的三分岔分流机器。它表达的是分类、路由或分配，不适合表示“运行中的系统”。

改为一台连续运转的生产机器：
- 单一方向的传送带；
- 机器内部持续进行加工；
- 产品沿同一条直线通过检测工位；
- 不出现分叉出口，不暗示分类决策。

## 核心叙事
1. 生产系统持续运行，产品沿直线传送带前进。
2. 检测装置捕捉产品偏差。
3. 红色反馈信号传到监测屏。
4. 控制台尚未改变参数时，错误输出继续产生。
5. 信号进入控制环，控制器调整参数，执行机构动作。
6. 绿色修正路径返回生产系统，后续输出变为合格模块。

## 动画实现
- 1600×900，16:9，22 秒。
- 生产机器与传送带作为独立素材/结构组合。
- 直线传送带延伸到检测工位，产品模块沿直线运动。
- 信号粒子沿 SVG 路径运动。
- 支持暂停、继续、重新播放、对齐辅助线。

## 验收
