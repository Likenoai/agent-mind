# 重复、积累与存量｜独立镜头

本目录制作增长机制前半段 Cue 05–06。两个镜头分别解释“存量与积累”的概念区别，以及“重复与积累”并非同一分类轴。

所有镜头保留原始口播、关键画面文字、全局 cue 位置和时长。用户确认后才嵌入总片。

## Cue 05｜积累是变化，存量是状态

**状态：** V1 已完成实际浏览器播放、关键帧与交互测试；等待用户视觉验收。尚未嵌入总片。

- 全局时间：00:59.153–01:18.483
- 时长：19.330612 秒
- 文件：[V1 独立预览](cue05-stock-accumulation-v1-standalone.html) · [可编辑源文件](cue05-stock-accumulation-v1-editable.html)
- 设计：一个透明储液容器；每期 4 个同尺寸单位流入、1 个同尺寸单位流出，净变化 +3。液位逐期上升，右侧时间序列显示每期变化，容器液位和当前存量数字表示某一时点的状态。
- 示意量：期初存量 10，每期净变化 +3，三期后为 19。数值仅为示意，不是实测数据。
- 验证记录：[Cue 05 V1 验证](cue05-validation.md)

**原始画面 / 动作：** 容器中每期流入和流出以同一单位示意，净变化单独显示。

**原始关键画面文字：** 存量：时点状态｜积累：变化过程

**原始口播：**

> 留存的成果进入某一时点的存量。积累描述存量形成和变化的过程，而存量是一种状态。行动反复发生，不表示存量必然增加；只有看留下来的成果和失去的成果，才能判断净变化。

## Cue 06｜重复与积累：不同分类轴

**状态：** V1 已完成实际浏览器播放、关键帧与交互测试；等待用户视觉验收。尚未嵌入总片。

- 全局时间：01:18.483–01:37.892
- 时长：19.408980 秒
- 文件：[V1 独立预览](cue06-repetition-accumulation-v1-standalone.html) · [可编辑源文件](cue06-repetition-accumulation-v1-editable.html)
- 设计：同一行动单元在同一时间轴上重复触发三次。A 系统每次都产生即时成果，但成果离开当前观察维度，不形成净留存；B 系统每次保留同尺寸成果，进入可调用存量。两边行动次数相同，只有留存情况不同。
- 示意比较：两种系统均行动 3 次；A 的存量变化为 0，B 的存量变化为 +3。没有积累不被表现为失败或垃圾处理。
- 验证记录：[Cue 06 V1 验证](cue06-validation.md)

**原始画面 / 动作：** 并列展示三次行动的流向与存量；同一时间轴，无真实数据。

**原始关键画面文字：** 行动次数不能代表净存量

**原始口播：**

> 比较两种假设：每次行动都得到即时成果，却没有在所考察维度留下存量；或者每次留下同样数量的成果。两者都可以重复行动，后者才在这个维度形成积累。没有积累不等于行动没有价值。

## 技术与验收

- 设计基准：1600×900、16:9。
- 技术：SVG + JavaScript + CSS；主体运动由绝对时间计算，支持 requestAnimationFrame、暂停、继续、重播和 seek。
- Cue 05：水滴粒子以相同尺寸运动，水位随净变化上升；右侧周期变化与当前存量状态分开呈现。
- Cue 06：两个系统的行动触发同步；输出物件尺寸一致；A 的成果逐次离场，B 的成果逐次留存。
- 当前为 V1 待用户视觉验收版本。未修改总片 HTML。
