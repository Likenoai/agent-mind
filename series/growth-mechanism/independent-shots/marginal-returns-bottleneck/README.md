1. 将原来同屏拥挤的三块内容拆为四个连续分镜：
   - 等量投入与额外产出递减；
   - 边际收益曲线；
   - 瓶颈、排队与资源损耗；
   - 结论收束。
2. 每个分镜独立占据主体画面，避免同屏堆叠。
3. 场景入场采用淡入与轻微位移；内部元素按顺序出现。
4. 转场不再使用大画面交叉叠加，改为前一画面先退场、后一画面再入场。
5. 片尾最后 0.45 秒，画面和字幕同步淡出。
6. 保留暂停、继续、重新播放和对齐辅助线。
