# 增长的流入与流出｜独立镜头 V3

## 重要约束：原始台词不改写
本镜头的同期讲解、关键画面文字、画面动作说明、字幕时间全部从仓库中的 `lecture-unified.html` 读取并保留。详见 `original-script-reference.md`。

## 核心画面
三个完全相同的透明储液舱并排比较：
- 左：流入 > 流出，水位从共同期初水位上升。
- 中：流入 = 流出，水位保持不变。
- 右：流出 > 流入，水位从共同期初水位下降。

每个储液舱使用同一张独立插画素材，液体、液面、入口流、出口流和粒子分别由程序控制。共同虚线表示相同的期初水位。

## 视觉边界
水箱只是结构隐喻。画面和字幕保留“同一可比较维度”的限制，不暗示技能、知识等复杂存量都能用单一数量衡量。

## 技术
- 16:9，1600×900。
- 独立 HTML，内嵌 PNG，无外部资源依赖。
- 原始镜头时长 22.752653 秒。
- 字幕切换点使用总片原音频字幕时间的相对偏移。
- 支持暂停、继续、重新播放和对齐辅助线。
