## 原则

- 保留总片原始台词和字幕时间，不因动画制作改写讲解内容。
- 独立镜头先完成、预览和验收；用户确认后再嵌入总片。
- 总片正式音频时间轴驱动字幕与动画，独立预览控件只用于单镜头验收。
- 镜头资源按版本归档；未确认镜头明确标记为 WIP。

## 资源说明

各 HTML 文件为单文件独立预览版本，图片资源已内嵌为 data URI（如该镜头使用 PNG/WebP）。可直接预览；需要单独编辑素材时，应从单文件 HTML 中提取图像或补齐独立 assets 目录。原始工程包仍保留在本对话文件中，仓库版本优先保存可预览、可复用的单文件工程。
