### 设计目标

沿用已获用户认可的瓶颈镜头制作方式：独立构图、动作级 SVG 组件、JavaScript 时间驱动、完整播放控制；单镜头确认后再嵌入总片。

### 视觉流程

1. 货架中的磨损、过时、失效部件依次离开存量。
2. 经过识别与分流装置，进入三条不同路径。
3. 维护：清洁与修补，恢复有效状态，返回货架。
4. 更新：机械臂安装新芯片，改善适用性，返回货架。
5. 淘汰：失效部件进入回收装置并退出系统，不再返回。
6. 货架保留维护和更新后的部件；淘汰位置留下空位，后续维护负担示意条下降。

### 技术实现

- 内联 SVG + JavaScript requestAnimationFrame + CSS。
- 五种部件状态采用相同的 100×64 坐标框，状态变化不改变物件外形尺寸。
- 通过 SVG path.getPointAtLength() 计算物件位置。
- 支持自动播放、暂停、继续、重新播放与时间轴 seek。
- 无外部图片依赖，单文件即可预览和编辑。
- 原始口播、关键画面文字、cue 时间均保持不变。

## 原脚本边界

- **同期讲解：** 存量不是无损保存的。遗忘、技能退化、工具过时和环境变化会削弱它的有效性。维护减少损耗，更新改善适用性，淘汰停止维持不值得留下的部分。必要时，少保留反而能减轻未来负担。
- **关键画面文字：** 不是留下越多越好，而是维护有效存量。
