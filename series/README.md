# 人生系列｜选题与内容规划

## 系列母题

**自主地塑造值得过的人生。**

帮助人理解现实、形成自己认可的方向，并在现实约束与他人共处中，有能力作出判断、采取行动和修正生活。

完整解释见 [母题文档](../foundation/mother-theme.md) 与 [可视化框架](../foundation/series-architecture.html)。

## 五个研究领域

1. 认识现实：我如何知道？
2. 形成方向：什么值得追求？
3. 作出选择：我应该怎么做？
4. 创造发展：我如何改变现实？
5. 与人共处：如何在相互依赖中生活？

这五个领域是研究索引，不是固定播放顺序，也不是互斥分类。一个主题可以跨领域连接。

## 选题排序原则

候选选题不以“哪个概念最有名”排序，而综合考虑：
- 对现实人生问题的重要性与普遍性；
- 理解后可能带来的判断或行动变化；
- 对后续主题的理论依赖价值；
- 观众的已有知识和认知负担；
- 是否有足够证据、案例和清楚的解释边界。

系列顺序可以迭代，不必强行设计成一条线性课程。

## 当前第一期：增长机制

[第一期定位与内容边界](01-growth-mechanism.md)

它不是单纯讲金融复利，而是回答：行动成果如何被留存、调用，并进一步改变未来行动的能力？

第一期的系列作用：
- 建立行动、成果、存量和未来行动之间的基本联系；
- 让观众理解重复、积累与复利式增长的区别；
- 为学习、记忆、选择、反馈和自我调节等后续主题建立认知接口。

## 单期内容模板

每个选题建立独立文档，至少记录：
1. 对应的人生问题；
2. 目标观众及其已有认识；
3. 希望带来的认知变化；
4. 核心理论与事实依据；
5. 核心解释、关联接口和不展开内容；
6. 与其他主题的依赖、协作或对照关系；
7. 传播主线与口播稿；
8. 现实应用、适用边界和风险；
9. 发布后的反馈与复盘。
