# 长期工作记忆｜知识研究工具

## 固定规则

研究复杂主题时，主动判断是否需要建立可视化知识结构，不要只用文字罗列概念。

优先采用：
- Markdown：完整记录概念定义、论证、证据、边界和结论。
- 概念图 / 概念关系网络图：展示概念层级和网状关系。
- 因果图 / 因果回路图：解释因果假设、反馈和系统动态。
- HTML + SVG：当节点多、关系复杂或需要交互探索时，制作可筛选、可点击的页面。
- PNG：作为展示或视频素材，不取代可编辑的结构源文件。

## 关系表达纪律

1. 不把相关概念自动视为同层概念。
2. 每条连线必须表达明确关系：分类、组成、过程、因果、支持、约束、反馈、评价或对照。
3. 区分层级结构与网状关系；允许跨层连接，但不抹平层级。
4. 不把相关、时间先后或逻辑依赖直接写成因果；因果边要标明证据状态。
5. 研究结构与观众认知路径始终分开维护。

## 主动提醒

当研究出现概念堆叠、层级混淆、关系不明确、因果过度推断时，主动建议绘制或更新概念关系网络。图与 Markdown 需要同步维护。
