# 项目记忆｜动画制作技术路线

> 更新：2026-11-27
> 适用项目：自媒体 / 人生系列 / 《人生机制与增长机制》

## 默认技术选择

后续机制动画默认采用：

- **SVG 原生矢量组件**：承担可独立控制的主体结构和动态元素。
- **JavaScript**：驱动运动、路径、循环、粒子、曲线、时间轴、暂停/恢复/seek。
- **CSS**：负责视觉样式、布局、背景、阴影及场景入场/转场/出场。
- **PNG / WebP**：用于复杂插画、纹理背景、边框、贴纸等不需要拆解内部动作的视觉素材。

简记：SVG 负责结构，JavaScript 负责运动，CSS 负责视觉与转场，PNG/WebP 负责复杂质感。

## 素材粒度

- 需要独立运动的部件不要合并成一张 PNG。
- SVG 也不要做成一整张不可拆解的大图；按动作关系拆成小组件。
- 复杂插画可以用 PNG/WebP，但要提供透明背景、统一画布、视觉中心和安全边距。
- PNG 嵌入 SVG 容器不等于真正的矢量化。
- 混合使用图片主体与 SVG 路径、遮罩、粒子和程序动画。

## 制作流程

1. 锁定原始台词、字幕、脚本位置和动作说明。
2. 设计单个镜头的视觉隐喻与构图。
3. 拆分素材和动画单元。
4. 独立制作完整 HTML 镜头。
5. 验收主体动作、入场、转场、出场、对齐、循环和时间轴。
6. 用户确认后再嵌入总片；未确认镜头不得修改总 HTML。
7. 总片音频时间轴驱动正式字幕和动画。

## 已验证的动画质量要求

- 连续运动优先于简单出现/消失。
- 物件沿路径运动时，不能在行程中途消失。
- 循环可以有等待间隔，但必须清楚表达完整行程。
- 画面切换要有完整入场、转场和出场。
- 位置、锚点、尺寸、边距、遮挡和裁切必须实际预览。
- 不能为了炫酷而扭曲知识关系。

## 概念表达特别规则：边际收益与瓶颈

- 边际收益递减：等量额外投入带来的新增产出逐次变小。
- 瓶颈：处理能力有限，导致输入排队、等待时间增加、通过频率受限，可能发生溢出或损耗。
- 瓶颈后面的输出物件应保持相同尺寸；不能画成越来越小或一路向下，否则会被误读为产出衰减或系统走下坡路。
