# Agent Mind｜人生理解与自主发展研究

> **工作母题：帮助人理解现实、形成自己认可的方向，并在现实约束与他人共处中，有能力作出判断、采取行动和修正生活。**

Agent Mind 是一个持续研究与内容传播项目。它不是人生成功学清单，也不是把所有知识强行归入一套理论，而是围绕真实人生问题，研究那些影响人认识现实、形成目标、作出选择、采取行动和与人共处的重要知识、能力与机制。

## 核心定位

- **价值方向：** 自主地塑造值得过的人生。
- **能力目标：** 发展现实能动性——理解现实、形成目标、判断与决策、行动、反馈修正，并能与他人合理共处。
- **认识工具：** 哲学、心理学、认知科学、社会科学及其他相关领域的理论与证据。
- **传播目标：** 把研究成果转化为观众能够理解、迁移到生活中的认识，而不是只传递术语或结论。

## 组织原则

1. **母题是价值与选题的地基，不是事实结论。** 新证据可以修正框架；不能为了符合框架而扭曲研究。
2. **人生问题是选题来源，理论机制是解释工具。** 不为了讲理论而虚构人生问题。
3. **研究结构与传播结构分开。** 研究按概念和证据关系组织；视频按观众理解问题的认知过程组织。
4. **知识地图允许网状关系。** 主题领域不是严格线性阶段，机制可以跨领域协作。
5. **内容深度由认知任务决定。** 核心解释深入讲，关联机制交代接口，独立延伸留在研究库。
6. **保留研究历史。** 现有专题路径尽量不移动，避免破坏旧链接；通过新目录、索引和导航完成架构迁移。

## 状态说明

当前母题是经过讨论后采用的工作锚点，不是不可修改的终极理论。每次重要研究和创作复盘，都可以提出修订，但需要说明触发证据、修订理由及对既有项目的影响。
