THE SERIES PREMISE / WORKING ANCHOR 1.0

自主地塑造
值得过的人生。

Agent Mind 的人生系列，不是提供一套替所有人决定人生的标准答案，而是帮助人理解现实、形成自己认可的方向，并在现实约束与他人共处中，有能力作出判断、采取行动和修正生活。

我们希望观众逐渐成为：能够理解现实、对自己的方向有理由、能够有效行动和修正，并承认他人也是主体的人。

一、把三个层次分开

价值目的决定方向，能力目标说明需要发展什么，知识与机制提供理解和行动工具。

VALUE PURPOSE

自主地塑造值得过的人生

最终价值方向，不由他人替自己定义，也不把财富、效率或增长当作唯一尺度。

CAPABILITY GOAL

现实能动性

理解情境、形成目标、基于理由判断、采取行动，并根据反馈和新信息持续修正。

KNOWLEDGE TOOLS

知识、理论与机制

通过哲学、心理学、认知科学、社会科学等研究，获得认识与行动能力。

现实约束不是个人努力就能消除的。身体、资源、环境、制度、权力关系、他人和偶然性都影响人生结果。这个系列不承诺完全控制人生。

二、现实能动性的五个研究领域

这是研究索引，不是严格互斥的心理学分类，也不是人生必须依次经过的五个阶段。

01 / KNOW

认识现实

我如何知道？

感知、注意、记忆、认知偏差、因果推理、概率判断、理解他人。

02 / VALUE

形成方向

什么值得追求？

兴趣、价值、动机、目标形成、内化、自主性、人生意义。

03 / CHOOSE

作出选择

我应该怎么做？

有限理性、决策、机会成本、风险、不确定性、承诺与退出。

04 / ACT

创造发展

我如何改变现实？

行动、学习、记忆、技能形成、迁移、增长、反馈、自我调节。

05 / RELATE

与人共处

如何在相互依赖中生活？

理解、信任、承诺、合作、协调、公平、权力、正义与制度。

三、系列如何持续迭代

母题不是教条。具体研究和现实反馈可以修正选题、结构，必要时也可以修正母题。

价值假设希望帮助人获得什么
人生问题现实中哪些问题重要
研究与解释事实、理论、证据、反例
传播与应用观众理解、判断、行动
反馈与修正修订框架和选题优先级

四、选题和讲解的双重顺序

选题顺序：人生问题 + 理论依赖

先问问题对人的生活有多重要，再考虑理解它需要哪些先行知识。不是单纯按学科章节排列。

研究顺序：事实与理论关系

先界定问题，核对事实，定位理论，比较证据和反例，形成可修正的认识。

视频顺序：观众认知过程

从已有认识出发，建立问题、制造认知差、解释关键机制、验证、限定边界，再落到生活。

内容深度：认知任务决定

核心解释深入讲；关联机制说明接口；独立延伸留在研究库。相关不等于必须展开。

五、已有项目如何接入新地基

不删除旧研究，也不为了符合新母题而改写旧结论。先重新定位，再逐步补充交叉关系。

六、当前母题的边界

不是成功学

不把财富、效率、地位或持续增长当作唯一人生尺度。

不是无限个人主义

人的选择和行动受到关系、责任、制度与他人主体性的约束。

不是全能控制论

发展能动性不意味着人可以控制所有结果。

不是知识百科

主题必须连接真实人生问题，并能说明学习价值与适用边界。
